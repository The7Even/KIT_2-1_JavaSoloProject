#### 세부적인 기능에 대한 구현
미국 주식 기능은 기본적으로 국내 주식에서 구현한 html 크롤링 기능을 거의 그대로 가져오면 되나, html의 구조의 차이가 있기에 이를 반영하여야 함.

가장 큰 차이는 해외 주식은 검색 결과가 1개 뿐이어도 일반적인 검색창에서 검색 결과가 뜬다는 것. 그리고 당연하게도 검색 결과에서 표출 위치가 다르다는 것.

데이터를 가져오는데에는 큰 문제가 없을 것으로 예상됨.

즐겨찾기 기능은 다음과 같은 csv 포맷으로 구성됨.

    1,1,"삼성전자",214800,20260429
    2,3,"BTC",112394850,20260501
    3,2,"로켓 랩",117.50,20260504

순서대로 번호, 종목종류(1-국내, 2-해외, 3-코인), 종목명, 추적시작가, 추적시작일 로 구성된 csv 데이터파일임.

저장 위치는 src/main/resources/com/example/stockscoinviewer/data/favorite.csv로 생각중에 있음.

아마도 즐겨찾기는 이후 모의 투자 기능으로 변경되겠지만, 이 기능은 종목 검색시 종목 Label 우측에 즐겨찾기 등록 버튼을 추가하여 추가할 수 있도록,

그리고 즐겨찾기탭에서 해제 버튼을 눌러 해제할 수 있도록 한다.
